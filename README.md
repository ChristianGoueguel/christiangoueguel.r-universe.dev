# christiangoueguel.r-universe.dev

Registry for <https://christiangoueguel.r-universe.dev>. R-universe builds
every package listed in `packages.json` and serves binaries for Windows,
macOS, and Linux.

```r
install.packages(
  "lwpls",
  repos = c("https://christiangoueguel.r-universe.dev", "https://cloud.r-project.org")
)
```
